# 一元二次方程的解法与判别式

资料性质：本资料是用于 Refine 检索的原创知识梳理，不替代教材、教师讲解或正式考试大纲。

## 定义与一般式

一元二次方程可整理为 `ax^2 + bx + c = 0`，其中 `a != 0`。整理前先把所有项移到等号一边，合并同类项，并确认最高次数确实是二次。

常见失误是忘记变号、把含有未知数的分母没有先处理，或把 `a = 0` 的一次方程误当成二次方程。

## 常用解法

### 因式分解法

当左边能分解为两个一次因式的乘积时，利用“两个因式乘积为零，至少一个因式为零”。例如：

`x^2 - 5x + 6 = 0` 可写成 `(x - 2)(x - 3) = 0`，所以 `x = 2` 或 `x = 3`。

### 配方法

把二次式化为平方形式，适合从函数、几何或完全平方结构出发的问题。配方时必须在等式两边同时补上同一个量。

### 求根公式

对 `ax^2 + bx + c = 0`，根为：

`x = (-b ± sqrt(b^2 - 4ac)) / (2a)`。

代入公式前要准确识别 `a`、`b`、`c` 的正负号，分母是 `2a` 而不是 `2`。

## 判别式

判别式记为 `Delta = b^2 - 4ac`。它用于判断实数根的情况：

- `Delta > 0`：有两个不相等的实数根。
- `Delta = 0`：有两个相等的实数根，也可说有一个实数根。
- `Delta < 0`：没有实数根。

判别式只说明根的数量和类型，不能直接代替求根过程；题目要求具体根时仍要继续计算。

## 根与系数的关系

若方程 `ax^2 + bx + c = 0` 的两个根为 `x1`、`x2`，则：

`x1 + x2 = -b / a`，`x1 * x2 = c / a`。

使用前提是二次项系数 `a` 不为零。此关系适合已知根求系数、已知系数求根的和积，或验证计算结果；不能把根的和、积与某一个根混淆。

## 检验与易错点

求出根后，应代入原方程检查。若原题含分式、根号或实际情境，还要检查定义域、分母非零和是否符合实际意义。不要只因计算得到一个数就直接作为答案。
