# 二次函数的图像、顶点与最值

资料性质：本资料是用于 Refine 检索的原创知识梳理，不替代教材、教师讲解或正式考试大纲。

## 基本形式

二次函数通常写成 `y = ax^2 + bx + c`，其中 `a`、`b`、`c` 是常数，且 `a != 0`。它的图像是一条抛物线。`a` 决定开口方向和图像的伸缩程度：

- `a > 0` 时开口向上，顶点处取得最小值。
- `a < 0` 时开口向下，顶点处取得最大值。
- `|a|` 越大，抛物线通常越“窄”；`|a|` 越小，图像通常越“宽”。

不要把 `c` 误认为顶点的纵坐标。`c` 是函数在 `x = 0` 时的值，即图像与 `y` 轴的交点纵坐标。

## 顶点与对称轴

对一般式 `y = ax^2 + bx + c`，对称轴为：

`x = -b / (2a)`。

把这个横坐标代入函数得到顶点纵坐标，因此顶点是：

`(-b / (2a), f(-b / (2a)))`。

顶点式 `y = a(x - h)^2 + k` 更容易读出图像信息：顶点是 `(h, k)`，对称轴是 `x = h`。注意括号中的符号：`y = a(x + 2)^2 - 3` 的顶点是 `(-2, -3)`，不是 `(2, -3)`。

## 最值与取值范围

顶点的纵坐标 `k` 是函数最值：

- 若 `a > 0`，最小值为 `k`，取值范围是 `y >= k`。
- 若 `a < 0`，最大值为 `k`，取值范围是 `y <= k`。

题目若限制自变量范围，例如 `x` 只在某个区间内取值，不能只看顶点。应比较顶点（若顶点在区间内）和区间端点的函数值。

## 由条件确定解析式

一般式中有 `a`、`b`、`c` 三个未知系数，通常需要三个独立有效条件。常见条件包括经过给定点、已知顶点、已知与坐标轴的交点或已知对称轴。

已知顶点 `(h, k)` 时，可以先写成 `y = a(x - h)^2 + k`。此时只剩 `a` 一个未知数；如果再给出一个不同于顶点的经过点 `(x1, y1)`，且 `x1 != h`，便可由：

`a = (y1 - k) / (x1 - h)^2`

唯一确定函数。若给出的“经过点”恰好就是顶点，它不会提供新的独立条件。

已知两个不同零点 `r1`、`r2` 时，可写成 `y = a(x - r1)(x - r2)`；再给出一个不在 `x` 轴上的经过点，可以确定 `a`。

## 解题检查清单

1. 确认 `a != 0`，并判断开口方向。
2. 明确题目要求的是顶点、对称轴、最值、取值范围还是解析式。
3. 写出公式后代入原条件复核，而不是只核对一个条件。
4. 解析式题检查独立条件是否足够；不要把重复信息当成新条件。
5. 图像题标出顶点、对称轴和与坐标轴的交点，再判断变化趋势。
