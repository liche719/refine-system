# 议论文的论点、论据与论证方法

资料性质：本资料是用于 Refine 检索的原创知识梳理，不替代教材、教师讲解或正式考试大纲。

## 三个基本概念

论点是作者要证明或主张的观点，通常可以用明确判断句概括。中心论点统领全文，分论点从不同角度支撑中心论点。

论据是用来证明论点的材料。事实论据包括事例、数据、现象、历史事实等；道理论据包括公认道理、定义、科学原理、格言或经过解释的权威观点。论据本身不是结论，必须说明它如何支持论点。

论证是把论据与论点连接起来的推理过程。阅读题中既要指出“用了什么材料”，也要回答“证明了什么、怎样证明”。

## 常见论证方法

### 举例论证

列举具体的人物、事件、现象或实验来证明观点。答题时可写：列举……的事例，具体有力地证明了……，从而增强了说服力。不要只因文中出现人名或故事就判定为举例论证，要看该事例是否服务于论点。

### 道理论证

引用或阐释普遍认可的道理、概念、规律来证明观点。它强调推理的严密性。若引用名言并用其证明论点，常可同时说明引用论证和道理论证的作用；具体答法应服从题目要求。

### 对比论证

把正反、好坏、成败或不同做法并列比较，突出某一观点的正确性或必要性。关键是两方面之间存在可比较关系，而不是文章中出现两个对象就一定构成对比。

### 比喻论证

用形象的事物说明抽象道理，使观点更易理解。比喻必须承担论证作用；纯粹描写性的比喻不一定是比喻论证。

## 答题步骤

1. 找到该段要证明的分论点或中心论点。
2. 判断材料与论点的关系，识别主要论证方法。
3. 用“方法 + 材料概括 + 证明的观点 + 表达效果”组织答案。
4. 题目问“作用”时，避免只答“增强说服力”，必须写出具体证明内容。

## 易错提醒

不能把修辞手法和论证方法完全等同；也不能脱离段落上下文只凭关键词判断。对同一段材料，若题目允许多种方法，应优先写最直接、证据最充分的一种并说明理由。
