# 一次函数与正比例函数

资料性质：本资料是用于 Refine 检索的原创知识梳理，不替代教材、教师讲解或正式考试大纲。

## 基本概念

一次函数通常写成 `y = kx + b`，其中 `k`、`b` 是常数且 `k != 0`。它的图像是一条直线。`k` 表示斜率，反映 `x` 每增加 1 个单位时 `y` 的变化量；`b` 是 `y` 轴截距，表示 `x = 0` 时的函数值。

正比例函数是一次函数的特殊情况：`y = kx`，即 `b = 0`。它的图像一定经过原点；一般的一次函数不一定经过原点。

## 图像与增减性

- `k > 0` 时，直线从左向右上升，`y` 随 `x` 增大而增大。
- `k < 0` 时，直线从左向右下降，`y` 随 `x` 增大而减小。
- 两条直线斜率相同且截距不同，则它们平行。
- 两条直线截距相同而斜率不同，则它们在 `y` 轴上相交。

画图时可以先取两个方便计算的点。若已知 `b`，点 `(0, b)` 很方便；也可以根据题意代入两个不同的 `x` 值求对应的 `y`。

## 由两个点确定解析式

已知直线经过两个横坐标不同的点 `(x1, y1)`、`(x2, y2)`，斜率为：

`k = (y2 - y1) / (x2 - x1)`。

再将任一点代入 `y = kx + b` 求 `b`。若 `x1 = x2`，两点确定的是竖直直线，不能写成 `y = kx + b`，因此公式的分母不能为零。

## 实际问题建模

把实际量写成一次函数前，先说明：自变量是什么、因变量是什么、单位是什么、取值范围是什么。通常“初始量”对应 `b`，“每单位变化量”对应 `k`。

例如计费问题中，固定费用常对应截距，单位数量的费用常对应斜率；但必须先看题目是否确实是线性关系，不能见到“费用”就默认一次函数。

## 常见错误

1. 把 `b` 当作斜率，或把 `k` 当作与 `y` 轴交点的纵坐标。
2. 两点求斜率时把分子和分母的顺序混用，导致符号错误。
3. 忽略实际问题的定义域，例如数量不能为负、时间范围有限。
4. 只写计算结果，不回代题目检查单位和实际意义。
